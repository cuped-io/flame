flame picks this visitor's variants from your project's rules file and never changes the page. Your code reads a variant with flame.getVariant('experiment-slug') once flame.ready resolves, and renders it.

goals — fired by your own flame.track() calls

flame listens to no click or submit for goals. Your page fires an event named after the goal with flame.track(goal.name) — which is what the backend matches conversions on. (pageview goals need nothing: flame sends the pageview itself.) 

{ "name": "checkout_complete", "type": "submit", "selector": "#checkout-form" }
